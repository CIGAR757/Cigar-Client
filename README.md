# Cigar Client

TheCigarMC's Minecraft client: a clean box-style mod menu in the Cigar blue → purple gradient, with
PvP and quality-of-life mods built in. It's a Fabric mod for **Minecraft 1.21.11**.

## Download & install

1. Download the latest `cigar-client-…+mc1.21.11.jar` from **[Releases](../../releases/latest)**.
2. Put it in the `mods` folder of a **Fabric 1.21.11** profile (Modrinth, Prism, CurseForge, or the
   vanilla launcher with Fabric Loader).
3. Launch the game. Fabric API is bundled, so nothing else is needed.

After that, Cigar Client **updates itself**. When a new version is released, it downloads in the
background and installs when you close the game. You can turn this off in the menu under
*Utility → Auto Update*.

## Controls

| Key | Action |
|---|---|
| Right Shift | Open the Cigar Client menu |
| C (hold) | Zoom (scroll to zoom further) |
| Left Alt (hold) | Freelook |

Change them in *Options → Controls → Key Binds → Cigar Client*.

## Mods

**HUD:** FPS, CPS, Ping, Keystrokes, Armor Status, Potion Effects, Coordinates, Direction, Time,
Server Address, Speed Meter, Combo Display, Reach Display, System Resources, Playtime, Stopwatch,
Pack Display

**PvP:** Toggle Sprint, Custom Crosshair, No Hurt Cam, Hitbox

**Visual:** Brightness, Low Fire, FOV Changer, Nametags, Scoreboard, Weather Changer, Time Changer

**Utility:** Zoom, Freelook, Tablist, Auto Update

Drag HUD elements anywhere with **Edit HUD Layout** in the menu.
